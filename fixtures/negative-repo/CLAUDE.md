# Orchard Notes — project instructions (synthetic negative control)

See @docs/style.md for naming rules.

## Workflow
- Never skip tests before merging.
- Don't always run the full suite; run the affected tests while iterating.
- Run unit tests on every change.
- Skip integration tests locally unless asked.
- Commit directly to a feature branch, never to main.
- Ask before adding a new dependency.

## Style
- Prefer named exports in library code.
- Use 2-space indentation.
- Write a comment where the intent is not obvious.
- Keep functions under 40 lines.

## Communication
- Be concise.
- When unsure, ask one clarifying question instead of guessing.
